# Lootopia — Front

Front-end du jeu **Lootopia** : application Next.js en TypeScript, avec support PWA.

## Fonctionnalités

- Interface de jeu en React et TypeScript
- Design system avec Tailwind CSS
- Installation sur l'écran d'accueil via `@ducanh2912/next-pwa`
- Linting et formatage intégrés (ESLint, Prettier)

## Stack

- **Next.js** — App Router
- **React** 18
- **TypeScript**
- **Tailwind CSS**
- **next-pwa** — installabilité et hors-ligne

## Démarrage

```bash
npm install
npm run dev
```

## Scripts

| Commande | Rôle |
| :--- | :--- |
| `npm run dev` | Serveur de développement |
| `npm run build` | Build de production |
| `npm start` | Sert le build de production |
| `npm run lint` | ESLint |
| `npm run format` | Prettier |
